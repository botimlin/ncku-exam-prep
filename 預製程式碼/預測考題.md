**結論：**
1. 演練試題說「不需要板子」，正式考試**還是用了實體板子**。
2. 演練試題的主題會直接變成正式考題的骨架。今年的演練試題是 ROS 2 + 位元/PIO/組語 + 臨界區/DMA，所以正式考題大概是「ROS 2 Host ↔ Pico 2」，再加上這些主題的實作和優化。
3. 去年 Host 和板子之間是用 **micro-ROS + micro-ros-agent** 溝通（不是自己定義序列埠封包）。今年很可能一樣，只是換成 Pico 2 + ROS 2 Jazzy → 範本在 `micro-ros/`。不過也可能直接用 USB 序列埠 → 範本在 `ros2/serial_bridge.py` + `pico/app_serial.c`。**兩種都要準備。**
4. 補充：micro-ROS 官方的 Pico 函式庫**還沒有正式支援 RP2350**（GitHub issue #1482，2025-10 提出，目前還沒解決；預編譯的 lib 是 RP2040 的 Cortex-M0+ 版本）。今年範例包的 Dockerfile 註解只提到 pico-sdk、cross toolchain、judge，沒有提到 micro-ROS。所以今年**「USB 序列埠 + 電腦端 bridge node」的可能性比去年高**，但出題老師也可能自己編好 micro-ROS。11/13 試前測試時看 repo 就知道是哪一種。

### 3. 硬體結論
- **板子：Raspberry Pi Pico 2（RP2350）**，可能好幾片（去年是 3 片）。雙核心，可以選 Cortex-M33 或 Hazard3 RISC-V。有 520KB SRAM、16 個 DMA channel（含 sniffer CRC；RP2040 是 12 個，別搞混）、3 個 PIO block（共 12 個狀態機）、32 個硬體 spinlock。
- **電腦端：** Docker 裡跑 Ubuntu + ROS 2 Jazzy + pico-sdk，用 USB（`/dev/ttyACM*`）連板子。
- **提交：** GitLab，CI 跑 judge。11/13 的試前測試要搞清楚 commit message 格式和 log 在哪裡看。
