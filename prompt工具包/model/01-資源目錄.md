# 目錄卡：我手上所有卡片的名稱（給模型看）
> 用法：模型說「【要卡】目錄 n」時貼第 n 張。由 `model/gen_catalog.py` 從卡片標題自動產生；卡片改了就重跑。每張 ≤ 1200 字元。
> 模型要卡片時寫「【要卡】編號」，例：「E01-02」「L02-02」「Q03-02」。操作者到 `編號卡/` 對應的查找檔 Ctrl-F 那個編號，複製下面那張。
