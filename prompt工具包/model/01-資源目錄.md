# 目錄卡：我手上所有卡片的名稱（給模型看）
> 用法：模型說「【要卡】目錄 n」時貼第 n 張。由 `model/gen_catalog.py` 從卡片標題自動產生；卡片改了就重跑。每張 ≤ 1200 字元。
> 模型要卡片時寫「【要卡】<系列名> <號碼>」，例：「規格卡 ROS 2」「參考卡 RP2350 DMA 2/8」「提示卡 建置 2/7」。操作者照 `model/README.md` 的對照表找到檔案，複製那一張。
