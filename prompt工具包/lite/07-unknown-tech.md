# 陌生技術速學（精簡版，備援）
目標：只學到能解這題的程度。先跑起來再讀。找類比。題目附的文件最可靠。每步設時間上限。

## 五步（共約 60 分）
1. **定位（5 分）**：是什麼類別（函式庫 / 框架 / 周邊 / 協定 / 工具 / 語言）？解決什麼？輸入輸出？在本題跟誰互動？像什麼我懂的東西？版本？
2. **跑起來（15 分）**：最小範例來源依序為題目附的範例 → 專案內已用到的地方（`grep -rn 關鍵字 .`）→ 官方 Getting Started → 官方 repo examples/tests → header 註解。原封不動先跑一次。
3. **建模型（15 分）**：一句話定義 + 類比 + 3–7 個核心概念與關係 + 生命週期 + 5–10 個關鍵 API + 限制（數量、對齊、單位、阻塞、執行緒安全）+ 陷阱。
   通用框架：**初始化 → 設定 → 啟動 → 等待 / 處理 → 釋放**。
4. **小改動（10 分）**：改一個參數，**先寫預測**再跑；預測錯的地方就是誤解。
5. **對準題目（10 分）**：題目用到哪些概念 / API？有哪些效能選項（buffer、批次、模式、硬體加速）？回到架構圖與優化流程。

## 依類別先找什麼
| 類別 | 先看 | 問 |
|---|---|---|
| 硬體周邊 | datasheet Overview、方塊圖、Programmer's model、SDK 範例 | 設定順序？FIFO / DMA / IRQ？時脈？資源數？|
| 函式庫 | header、範例 | 初始化順序？阻塞？記憶體誰管？回傳值？|
| 框架 | 架構概念、CLI | 誰呼叫誰？callback 在哪個執行緒？|
| 協定 | 封包格式、狀態機 | 分框、校驗、流控、endianness |
| 工具 | `--help`、man | 最常用 5 個指令 |

## 讀 header
```bash
grep -n "^[a-z].*(" x.h | head -50      # 函式
grep -n "typedef\|struct\|enum" x.h     # 型別
grep -rn "x_init\|x_start" examples/ src/
```
datasheet 搜尋 "must" "note" "errata" "not supported"。
